Songlinks (self-hosted)

index.html is fully self-contained (styles and code are inside it).
Upload these files to the root of your GitHub Pages repo (same names, replace the old ones):
  index.html, sw.js, manifest.webmanifest, icon-192.png, icon-512.png
You can delete app.js from the repo; it is no longer used.

Search tab: the Internet Archive works right away. For Jamendo (songs, artists, albums, playlists),
get a free client ID at https://devportal.jamendo.com/ and paste it in once.
