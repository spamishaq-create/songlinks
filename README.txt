Songlinks (self-hosted)

index.html is fully self-contained (styles and code are inside it).

For saving songs offline you need to open it from a web address (https), not from the Files app:
1. Upload ALL files in this folder to a free static host (GitHub Pages, Netlify, Cloudflare Pages).
2. Open the address in Chrome on your Android phone.
3. Chrome menu (three dots) > Install app (or Add to Home screen).
4. Search tab: Internet Archive works right away. For Jamendo, get a free client ID at
   https://devportal.jamendo.com/ and paste it in once.
